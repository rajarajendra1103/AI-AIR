🌐 Live Open-Meteo API Integration

• Geocoding Service: Resolves global city queries into geographic latitude and longitude.
• Real-Time Weather: Fetches temperature, relative humidity, wind speed, wind direction, and surface pressure.
• Air Quality Telemetry: Fetches hourly PM2.5, PM10, NO2, SO2, CO, O3, and NH3 values.
• 14-Day Resampling: Aggregates historical 14-day hourly readings into [14, 10] daily feature sequences fed directly into PyTorch models.

🤖 PyTorch Deep Learning Models

• LSTM (`LSTMForecaster`): 2-layer stacked Long Short-Term Memory network capturing long-term dependencies.
• GRU (`GRUForecaster`): 2-layer stacked Gated Recurrent Unit offering computational efficiency.
• Transformer (`TransformerForecaster`): Time-series Multi-Head Self-Attention Encoder with sinusoidal positional embeddings.

🩺 Weather-Aware AI Health Advisory Agent

• Supported Profiles: General Public, Asthma/Respiratory, Cardiovascular/Heart Disease, Elderly (65+), Children & Infants, Outdoor Athletes.
• Safety Scoring: Custom 0–100 sensitivity metric weighted by underlying vulnerability and ambient pollutant concentration.
